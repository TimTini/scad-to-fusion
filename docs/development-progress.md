Scope: source-driven conversion of the documented OpenSCAD subset to standalone Autodesk Fusion Python scripts. The current baseline has 93 offline tests, 19 native cases and four toothbrush mesh comparisons. Detailed evidence is linked from testing.md and toothbrush-validation.md.

Publication uses a fresh Git history containing source, fixtures, tests, tools and sanitized documentation/evidence. Private prompts, local work logs, machine paths, runtime output and environment files are excluded. Numeric evidence and source hashes are retained; paths in evidence identify relative artifacts rather than a developer machine.

## Native simplification implementation plan

Goal: fewer selectable faces/edges and editable native rounding on the actual model, with source geometry and parameter behavior checked independently.

- [x] Recover high-resolution circular runs only when coordinate expressions prove matching center/radius and sin/cos angle; preserve ordinary polygon intent. Test malformed/changed runs and the real source profile.
- [x] Reconstruct supported tangent quarter-circle corners as sharp Revolve geometry followed by native Fillet; link source radius expressions. Keep unsupported profile shapes explicit and retain exact polygon support.
- [x] Integrate smooth circular-section helical Loft into generation with original phase, pitch and taper. Evaluate its approximation on the whole model and functional sections; report rebuilding requirements honestly.
- [x] Run offline regression, independent review, isolated Fusion baseline/parameter/assembly checks and mesh comparisons. Count faces/edges and record health.
- [x] Commit/push the verified implementation on this branch, keeping public main's baseline recoverable.
